# Netflix Data Analysis using SQL

## About
Analyzed Netflix content data using MySQL to find trends in countries, genres, ratings and directors.

## Tool Used
- MySQL Workbench 8.0

## Dataset
- Source: Kaggle - Netflix Movies and TV Shows

## Queries Covered
- Movies vs TV Shows count
- Top 5 countries with most content
- Most common age ratings
- Top 5 directors
- Content by release year
- Top 5 genres
- Movies longer than 90 minutes
- Top 10 longest movies
- Top 5 countries for movies only
- Top 5 TV Shows by seasons
